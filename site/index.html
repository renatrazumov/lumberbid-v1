How a sealed timber sale works

  1. Spec the lot. Species, diameters, length, access, metal disclosure — start with the log value estimator.
  2. Qualified buyers bid sealed. No one sees anyone else’s number before close — the format state forestry sales have used for decades, because it protects the seller.
  3. Close is the public reading. Highest bid wins; the full bid sheet becomes visible — you see exactly what every buyer offered.
  4. Money moves on the funded rail. The winner’s payment settles through timber.bid’s escrow engine — a won lot is a funded deal, not a handshake.
